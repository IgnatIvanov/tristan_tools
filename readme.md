# Набор различных скриптов для построения отчётов и работы с данными

## Установка
- установить python
- создать виртуальное окружение в корне проекта: python -m venv .venv
- активировать виртуальное окружение
- установить необходимые пакеты: pip install -r requirements.txt
- Для работы с Dolphin требуется добавить в проект апи ключ. Строку ключа без переносов и дополнительных символов нужно разместить в текстовом файле по пути services/dolphin/access/integration_auth_key.txt
